Términos de uso y política de privacidad

Última actualización: 2026

1. Finalidad de la aplicación

Gestor de Talentos FM es una aplicación web desarrollada con fines académicos como parte de un Trabajo de Fin de Grado. Su objetivo es permitir el análisis, comparación y agrupación de jugadores a partir de archivos exportados desde Football Manager.

2. Uso de la cuenta

El registro permite al usuario subir sus propios archivos HTML, asociarlos a su cuenta y consultar los análisis generados por la aplicación.

3. Datos almacenados

La aplicación puede almacenar el nombre, correo electrónico, contraseña cifrada y archivos HTML subidos por el usuario. Las contraseñas no se guardan en texto plano, sino mediante un sistema de hash.

4. Archivos subidos

Los archivos HTML subidos por el usuario se utilizan únicamente para extraer información de jugadores y generar análisis dentro de la aplicación.

5. Responsabilidad del usuario

  • El usuario debe subir únicamente archivos relacionados con el funcionamiento de la aplicación.
  • El usuario es responsable del contenido de los archivos que importa.
  • No se debe utilizar la aplicación para subir contenido malicioso, ilegal o ajeno al propósito del proyecto.

6. Limitación de responsabilidad

La aplicación se ofrece como proyecto académico y demostrativo. Los resultados de comparación, clustering y análisis deben interpretarse como apoyo visual y estadístico, no como decisiones deportivas definitivas.

7. Privacidad

Los datos del usuario se utilizan únicamente para el funcionamiento interno de la aplicación. No se venden ni se comparten con terceros.

8. Aceptación

Al crear una cuenta, el usuario acepta estos términos de uso y autoriza que sus archivos y análisis queden asociados a su cuenta dentro de la aplicación.

Puedes cerrar esta ventana cuando termines de leer los términos.

Preguntas frecuentes sobre el Gestor de Talentos

Resuelve dudas sobre la importación de jugadores, la comparación de perfiles, los algoritmos de clustering y el uso de métricas deportivas dentro de la aplicación.

Dudas principales de la aplicación

Esta sección explica las funciones más importantes del sistema y cómo interpretar los resultados generados a partir de los datos de Football Manager.

Para importar jugadores, debes subir un archivo HTML exportado desde Football Manager. Si has iniciado sesión, la página principal muestra una sección de importación donde puedes seleccionar el archivo y cargarlo en el sistema. Después, la aplicación procesa los datos y actualiza la base de jugadores disponible.

La aplicación trabaja con una base de datos para almacenar la información procesada de los jugadores. El archivo HTML sirve como fuente de entrada, pero el sistema estructura esos datos para poder filtrarlos, mostrarlos en tablas, compararlos y utilizarlos en los módulos de análisis.

Puedes buscar jugadores por nombre, edad, posición, titularidad y métricas como goles, asistencias o disparos. Estos filtros ayudan a localizar perfiles concretos dentro de la base de datos sin tener que revisar toda la tabla manualmente.

La comparación permite seleccionar dos futbolistas y analizar sus datos lado a lado. El sistema muestra una tabla comparativa, un gráfico radar con métricas normalizadas y un mapa de posiciones para visualizar la zona habitual de cada jugador.

La aplicación evita comparaciones poco útiles entre jugadores con roles incompatibles. Por ejemplo, no tendría sentido comparar directamente un portero con un delantero usando las mismas métricas. En cambio, sí permite comparar jugadores que comparten una posición o una zona de juego similar.

El gráfico radar representa varias métricas del jugador en una escala normalizada. Esto facilita ver rápidamente qué jugador destaca más en aspectos como rendimiento, goles, asistencias, pase, recuperación o estadísticas específicas según su rol.

El clustering agrupa jugadores con características similares a partir de sus métricas. Sirve para detectar perfiles parecidos, encontrar alternativas a un jugador concreto o descubrir futbolistas que tienen un rendimiento similar dentro de una misma posición.

K-Means divide los jugadores en un número concreto de grupos, por lo que es útil cuando se quiere clasificar los perfiles en varios conjuntos definidos. DBSCAN, en cambio, agrupa jugadores según la densidad de los datos y puede detectar perfiles atípicos o jugadores que no encajan claramente en ningún grupo principal.

Las métricas importantes no son las mismas para todos los roles. Un portero, un defensa, un centrocampista y un delantero se evalúan de forma distinta. Por eso la aplicación separa los análisis por posición y usa variables más representativas para cada perfil.

Puedes consultar algunas funciones generales sin iniciar sesión. Sin embargo, para importar tus propios archivos HTML y gestionar tus datos personalizados, necesitas tener una cuenta e iniciar sesión en la aplicación.

xG significa goles esperados y estima la calidad de las ocasiones de gol. xA significa asistencias esperadas y mide la probabilidad de que un pase termine en gol. Las métricas por 90 minutos permiten comparar jugadores aunque hayan disputado diferente cantidad de minutos.

La aplicación incorpora técnicas de análisis de datos y aprendizaje automático no supervisado, como K-Means y DBSCAN, para agrupar jugadores según patrones de rendimiento. No sustituye el criterio deportivo, pero ayuda a detectar relaciones y perfiles que serían más difíciles de identificar manualmente.
